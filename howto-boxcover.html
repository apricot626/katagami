収納ボックスカバーの作り方

カラーボックスや収納ケースにかぶせる布カバー。天面1枚と側面4枚を縫い合わせる、シンプルな箱型です。中身が見えなくなるだけで、部屋がすっきり片づいて見えます。生地を替えるだけで模様替えができるのも利点。型紙はすべて直線なので、印刷せずに直接裁つのが手軽です。

1. 材料と道具

材料（標準サイズの目安）

  • 表布（リネン・帆布・厚手コットンなど）— 約 110cm幅 × 100cm
  • お好みで：裾に通すゴムひも
  • お好みで：接着芯（天面に張りを出したいとき）

道具

  • ミシン（または針と糸）
  • チャコペン・鉛筆
  • 定規・はさみ
  • アイロン
  • まち針またはクリップ

2. 型紙の作り方（カタガミで自動生成）

カタガミの型紙ツールを使うと、仕上がりサイズを入力するだけで縫い代付きの型紙を自動計算してA4に分割印刷できます。

  1. ツールを開く
    型紙ツールを開き、上部タブの「ホーム」→「収納ボックスカバー」を選択します。
  2. サイズを入力する
    「箱の幅」「奥行」「かぶせる高さ」「ゆとり」を入力します。小さめ・標準・カラーボックスのプリセットがあります。
  3. 縫い代を設定する
    下部スライダーで縫い代幅を選びます（初心者は 1.0〜1.5 cm がおすすめ）。
  4. 印刷する
    「印刷する（A4・実寸）」ボタンを押し、印刷ダイアログで倍率 100%・用紙に合わせるをオフにして印刷します。 1枚目の案内シートにある50mm校正枠を定規で確認してください。

3. 布の裁断

  1. 箱を測る
    箱の幅・奥行・かぶせたい高さを測ります。ゆとりを入れないとかぶりません。プリセットのゆとりをそのまま使ってください。
  2. 裁ち切り寸法を確認する
    すべて長方形なので、型紙を印刷せず、案内シートの寸法どおり布に直接線を引いて裁つのがおすすめです。
  3. 裁断する
    天面1枚、側面（前・後）2枚、側面（左・右）2枚、合計5枚を裁ちます。
  4. 端の処理
    縫い代の端にジグザグミシンをかけておきます。

4. 縫い方

4-1. 側面をつなぐ

  1. 側面4枚を、前 → 右 → 後 → 左 の順に中表で縫い合わせ、輪にします。
  2. 最後の1辺を縫うときは、輪になるので布が回りにくくなります。ミシンの腕に通してゆっくり進めてください。
  3. 縫い代を割ってアイロンで押さえます。

4-2. 天面を付ける

  1. 輪にした側面の上端と、天面を中表に合わせます。
  2. まず四隅を合わせてまち針で留め、そのあいだを細かく留めていきます。角がきちんと合っているかが仕上がりを決めます。
  3. 1周縫います。角に来たら、針を刺したまま押さえを上げ、布を90度回してから続けてください。
  4. 角の縫い代を斜めに切り落とします。

4-3. 裾を始末する

  1. 裾を1cm→2cmの三つ折りにして縫います。
  2. ゴムを通す場合は、通し口を3cm残して縫います。

4-4. 表に返してかぶせる

  1. 表に返し、角を目打ちで整えてアイロンをかけます。
  2. 実際に箱にかぶせて確認します。天面が浮く場合は、ゆとりが多すぎるので側面の縫い代を増やして調整してください。
  3. ゴムを通す場合は、裾まわりの実寸の85%程度の長さに切って通し、端を縫い留めます。

✏️ 天面を付けるときの角合わせが唯一のポイントです。側面の縫い目が天面の4つの角にぴったり来るように、先に四隅をまち針で留めてから、あいだを埋めてください。ここがずれると、かぶせたときに全体がねじれます。

5. コツと応用

  • 直接裁つのが早い：すべて長方形なので、A4を貼り合わせるより定規で線を引いたほうが正確で早いです。
  • 天面に接着芯：天面がへこむのが気になる場合は、接着芯を貼ると張りが出ます。
  • 取っ手を付ける：前面に共布のループを付けると、引き出すときに便利です。
