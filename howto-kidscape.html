キッズマントの作り方

仮装にも防寒にも使えるマント。裾まわりの長方形を衿ぐりでギャザーに寄せ、衿のバンドで受けます。首もとはひもで結ぶので、サイズが多少合わなくても着られます。直線裁ちだけで、袖も身頃の合わせもありません。ハロウィンや発表会に、前日でも間に合います。

2. 型紙の作り方（カタガミで自動生成）

カタガミの型紙ツールを使うと、仕上がりサイズを入力するだけで縫い代付きの型紙を自動計算してA4に分割印刷できます。

  1. ツールを開く
    型紙ツールを開き、上部タブの「子供服」→「キッズマント」を選択します。
  2. サイズを入力する
    「着丈」「裾まわり」「首まわり」「衿の高さ」「結びひもの長さ」を入力します。100cm・120cm・140cmのプリセットがあります。
  3. 縫い代を設定する
    下部スライダーで縫い代幅を選びます（初心者は 1.0〜1.5 cm がおすすめ）。
  4. 印刷する
    「印刷する（A4・実寸）」ボタンを押し、印刷ダイアログで倍率 100%・用紙に合わせるをオフにして印刷します。 1枚目の案内シートにある50mm校正枠を定規で確認してください。

3. 布の裁断

  1. 着丈を決める
    首の付け根から、マントの裾にしたい位置までを測ります。ふくらはぎの中ほどまでが動きやすい長さです。床につくと踏みます。
  2. 型紙を布に写す
    身頃・衿・結びひもを写します。身頃は後中心を「わ」に置いてください。すべて長方形です。
  3. 裁断する
    身頃1枚（後中心わ）、衿を表布・裏布 各1枚、結びひもを2本裁ちます。
  4. 端の処理
    裾と前端は三つ折りにするので不要です。上端（ギャザーを寄せる辺）にジグザグをかけておくと、ギャザーを寄せるときにほつれません。

4. 縫い方

4-1. 裾と前端を三つ折りにする

  1. 前端（左右の脇）を1cm→1cmの三つ折りにして縫います。
  2. 続けて裾も1cm→2cmの三つ折りにして縫います。
  3. 先に済ませてください。衿を付けてからでは布が回りにくくなります。
  4. サテンはすべるので、アイロンで折り目をしっかり付けてから縫ってください。

4-2. 上端にギャザーを寄せる

  1. 上端から5mmと1cmの位置に、ミシンの縫い目を粗く（4mm程度）2本入れます。返し縫いはしません。
  2. 上糸を2本まとめて引き、布を寄せてギャザーを作ります。片側ずつ引くと均等になります。
  3. 衿の長さに合うまで寄せます。裾まわりの4倍前後を首まわりに寄せることになるので、しっかりたっぷり寄ります。
  4. ギャザーが片寄らないよう、指でしごいて均等に散らしてください。

4-3. 衿を付ける

  1. 結びひもを4つ折りにしてステッチします。
  2. 衿の表布と、ギャザーを寄せた身頃の上端を中表に合わせて縫います。両端にひもの端を挟み込んでください。
  3. 衿の裏布を重ね、上辺と両端を縫います。
  4. 表に返し、衿の裏布の縫い代を折り込んで、身頃との縫い目に落としてまつります。

4-4. 仕上げる

  1. 衿の周囲から3mm内側をぐるりとステッチします。
  2. ギャザーを寄せるために入れた粗い縫い目を、見えている範囲で抜きます。
  3. 実際に着せて、首もとがきつくないか、丈が長すぎないかを確認してください。

✏️ ギャザーを寄せる粗い縫い目は、必ず2本入れてください。1本だと、引いたときに布がねじれて、ギャザーが片側に寄ります。2本のあいだに布が挟まれることで、まっすぐなひだになります。糸を引くときは、両端から少しずつ交互に引くのがこつです。

5. コツと応用

  • ハロウィンなら黒サテン：裏を赤にすると、翻ったときに見えて本格的になります。フェルトなら端の始末すら要りません。
  • フリースであたたかく：フリースで作れば、真冬の羽織りものになります。端がほつれないので裾の始末も不要です。
  • フードを足す：衿のかわりにフードを付けると、赤ずきんや魔法使いになります。フードは半円2枚を縫うだけです。
