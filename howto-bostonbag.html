ボストンバッグの作り方

1〜2泊の旅行やジム通いに使える大容量のバッグ。マチが「底と両脇が続いた1本の帯」になっているので、本体2枚に縫い付けるだけで箱型ができます。縫い合わせは実質2回。大きく見えますが、構造は驚くほど単純です。帆布やナイロンで作ります。

1. 材料と道具

材料（2泊サイズの目安）

  • 表布（帆布8〜11号、ナイロンなど）— 約 110cm幅 × 150cm
  • 裏布（シーチング・ナイロンなど）— 同量
  • 接着芯（厚手）— 本体分
  • アクリルテープ（持ち手用、4cm幅）— 指定の長さ × 2本
  • ファスナー（袋口の幅程度）— 1本
  • お好みで：底に敷く底板（プラスチックダンボール）

道具

  • ミシン（または針と糸）
  • チャコペン・鉛筆
  • 定規・はさみ
  • アイロン
  • まち針またはクリップ

2. 型紙の作り方（カタガミで自動生成）

カタガミの型紙ツールを使うと、仕上がりサイズを入力するだけで縫い代付きの型紙を自動計算してA4に分割印刷できます。

  1. ツールを開く
    型紙ツールを開き、上部タブの「バッグ」→「ボストンバッグ」を選択します。
  2. サイズを入力する
    「仕上がり幅」「高さ」「マチ」「持ち手の長さ」「持ち手の裁ち幅」「底角の丸み」を入力します。1泊・2泊・スポーツのプリセットがあります。
  3. 縫い代を設定する
    下部スライダーで縫い代幅を選びます（初心者は 1.0〜1.5 cm がおすすめ）。
  4. 印刷する
    「印刷する（A4・実寸）」ボタンを押し、印刷ダイアログで倍率 100%・用紙に合わせるをオフにして印刷します。 1枚目の案内シートにある50mm校正枠を定規で確認してください。

3. 布の裁断

  1. 型紙を布に写す
    本体（前・後）・マチ（底＋両脇の続き）・持ち手の3パーツを写します。マチは細長い帯で、全長は「幅＋高さ×2」です。
  2. 裁断する
    本体を表布・裏布 各2枚、マチを表布・裏布 各1本、持ち手を2本裁ちます。マチが長いので、布の長さ方向に取ってください。
  3. 接着芯を貼る
    表布の本体とマチの裏面に厚手の接着芯を貼ります。自立させたいので省かないでください。
  4. 端の処理
    裏布を付けるので基本的に不要です。

4. 縫い方

4-1. 持ち手を作る

  1. 共布で作る場合、4つ折りにしてアイロンで押さえ、両端から3mmをステッチします。芯テープを挟むと持ちやすくなります。
  2. アクリルテープを使う場合は、指定の長さに切り、切り口をライターで軽くあぶってほつれ止めします。

4-2. 持ち手を本体に付ける

  1. 本体（表布）の前後それぞれに、持ち手を縫い付けます。左右対称の位置に置いてください。
  2. 持ち手の端から、本体の高さの3分の1くらいまで縦にステッチを2本入れ、上端は四角に×を描くように縫って補強します。
  3. この「縦に長く縫い付ける」形が、重い荷物を入れても抜けない秘訣です。上端だけを縫うと必ず外れます。
  4. 本体が平らなうちに済ませるのが鉄則。組み立ててからでは押さえが届きません。

4-3. マチを付ける

  1. マチの中央（合印）を本体の底の中央に合わせ、まち針で留めます。
  2. そこから左右へ、底 → 底角のカーブ → 脇 の順に、少しずつ留めながら進めます。
  3. 底角のカーブでは、マチ側の縫い代に5mm間隔で切り込みを入れると、無理なく曲がります。
  4. 1周（正確には底から両脇の上端まで）縫います。もう1枚の本体も同じようにマチに縫い付けます。
  5. 裏布も同じように組み立てます。ただし、マチの片側に返し口として15cm縫い残しておきます。

4-4. ファスナーを付けて仕上げる

  1. 表布を表に返し、裏布は裏のまま。表布を裏布の中に、中表になるように入れます。
  2. 袋口にファスナーを挟んで1周縫います。ファスナーは半分開けた状態で縫うと、あとで返せます。
  3. 裏布の返し口から全体を表に返し、返し口を閉じ、裏布を中に押し込みます。
  4. 袋口から5mm内側をぐるりとステッチしたら完成です。
  5. 底板を入れる場合は、底の大きさに切ったプラダンを最後に差し込みます。

✏️ マチを付けるときは、必ず「中央から左右へ」進めてください。端から縫っていくと、最後に必ず長さが合わなくなります。中央の合印を底の中央に合わせ、そこから均等に振り分けていけば、誤差は両端に少しずつ分散して目立ちません。

5. コツと応用

  • 持ち手の縫い付けが命：旅行バッグは重いものを入れます。持ち手は本体の高さの3分の1まで縦に縫い付けてください。ここを手抜きすると必ず抜けます。
  • 底板で形が保てる：プラスチックダンボールを底の大きさに切って入れると、荷物を入れても底が落ちません。
  • 肩紐を足す：両脇にDカンを付けておけば、あとからショルダーストラップを付けられます。長距離ならこれが助かります。
