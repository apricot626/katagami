# カタガミ レビューチェックリスト

サイトを見直すときの手順書です。**自動**の項目は `node scripts/audit.js` が全部見てくれるので、
人の目は**手動**の項目に集中してください。

```bash
node scripts/audit.js     # 0件になればOK（1件でもあれば終了コード1）
```

## 0. 変更を入れたあとに必ず流すもの

型紙・ガイドを触ったら、この順で回してから確認します。順番に意味があります。

```bash
node scripts/gen-ja-howto.js        # 和文ガイドを生成（データにあるキーだけ）
node scripts/gen-en-howto.js        # 英文ガイドを生成
node scripts/inject-howto-figs.js   # 各ガイドに図解SVGを挿入
node scripts/enrich-material-links.js  # 材料ボックスの楽天リンクを組み直す
node scripts/sync-hreflang.js       # 英語版の有無に合わせて hreflang を整える
node scripts/gen-ogp.js             # OGP画像（引数でキーを絞れる）
node scripts/audit.js               # 点検
```

`gen-ogp.js` はローカルサーバーが要ります。

```bash
python3 -m http.server 8099 &
node scripts/gen-ogp.js bostonbag neckpillow   # キー指定で部分生成
```

## 1. 型紙の製図　【自動】

| 見るところ | なぜ |
|---|---|
| 全パラメータの**最小値・最大値・全プリセット**で例外が出ないか | 既定値だけ動けばいいわけではない。端の値で破綻しがち |
| 座標に NaN / Infinity がないか | 1つでも混ざると描画が消える |
| パーツの縦横が 0 でないか、4m を超えていないか | 計算の符号ミスや単位ミスの兆候 |
| 縫い代線が出来上がり線から離れすぎていないか（3倍超） | **角の丸み半径が辺より大きい**と自己交差してトゲが出る |
| memo に `undefined` / `NaN` / `${}` が出ていないか | データの取りこぼし |

### 過去に踏んだ落とし穴

- **丸み半径が辺の半分を超える**：`round` の max が他の寸法の min より大きいと壊れる。
  `clampR(半径, 辺A, 辺B)` を必ず通すこと（`patterns.js` 冒頭のヘルパー）。
- **衿ぐりが身頃をはみ出す**：首回りを胴回りと独立に入力させると、首回りを最大にしたとき
  衿ぐりの曲線が脇を追い越す。相手の寸法に対する割合で上限を掛ける。
- **重複した頂点**：同じ座標が連続すると長さ0の辺ができ、法線が定まらない。`pieceFrom()` の
  `dedupe()` が吸収するので、生成側で頂点を重ねても大丈夫。
- **鋭角の角**：フレアスカートの裾など、角が鋭いと縫い代線が長く飛び出す。
  `offsetPolygon()` にマイター制限（2.5倍）が入っているので自動で面取りされる。
- **袖の製図**：袖幅は**身頃の袖ぐりの実長**から出す。パーツの高さがそのまま入力した袖丈になるよう、
  袖山は浅く（2.5〜3.5cm）取る。袖山を深くすると、入力した袖丈より実際が短くなる。

## 2. HTML の基本　【自動】

- `<title>` / `meta description` がある
- `<title>` にエスケープしていない `&` がない（`&amp;` にする）
- **二重エスケープ**していない（`&amp;amp;` が出ていないか）
- `id` が重複していない
- `<html lang>` が ja / en で正しい
- `<h1>` がちょうど1つ（ツール画面は `.sr-only` で補っている）
- 見出しレベルが飛んでいない（h2 → h4 など）
- 本文に `${...}` / `undefined` / `NaN` / `[object Object]` が漏れていない

## 3. リンク　【自動】

- 相対リンクの先が実在する（`href` / `src` 両方）
- `tool.html?p=xxx` のキーが `PATTERNS` に実在する
- 削除したページは**リダイレクト用ページを残す**（`meta refresh` ＋ canonical ＋ noindex）。
  監査はリダイレクトページを自動で対象外にします。

## 4. canonical / hreflang / sitemap　【自動】

- canonical が自分自身の正しいURLを指している
- **hreflang は必ず相互参照**。片側だけだと Google に無視される
  （英語版がないページには hreflang を出さない。`sync-hreflang.js` が面倒を見る）
- 英語版がないページの「English」リンクは、英語トップか英語の作り方一覧へ送る
- sitemap の URL が実在し、重複がなく、全ページが載っている

## 9. 英語の質　【手動】

自動では拾えません。追加・変更したときに読んでください。

### つづりは**米式**に統一

サイト全体で米式が優勢なので、そちらに寄せています。

| 使わない（英式） | 使う（米式） |
|---|---|
| colour / centre / metre | color / center / meter |
| organise, organiser | organize, organizer |
| nappy / pushchair / pyjama | diaper / stroller / pajama |
| towelling / labelled / cosy / aluminium | toweling / labeled / cozy / aluminum |

### 和製英語に気をつける

| 日本語 | ✗ そのまま英語にすると | ✓ 実際の英語 |
|---|---|---|
| ボディバッグ | body bag（**遺体袋**の意味） | sling bag / crossbody bag |
| マナーベルト | manner belt（通じない） | belly band |
| ワンピース | one-piece（水着の意味になる） | dress |
| ホック | hook（あいまい） | snap / hook-and-loop |
| ペットボトル | pet bottle | plastic bottle |
| ハーフパンツ | half pants | shorts |
| ウエストポーチ | — | belt bag / waist pack（fanny pack は英国で下品な語） |

### そのほか

- 商品名として括弧に動詞句を入れない（`Cosmetic pouch (stands up)` → `(stand-up)`）
- 日本固有のものは英語名＋原語の説明を添える（`Hanten (Japanese padded jacket)`）
- 単数・複数、冠詞（`for a tote bag` / `for pants`）。`gen-en-howto.js` が
  複数形・不可算名詞のリストで出し分けています。新しく複数形の名前を足したらリストに追加を

## 10. 日本語の読みやすさ　【手動】

### 数値の目安（`ja-howto-data.js` 全体）

- 1文の長さ：中央値25〜30字、90%が45字以内、**95字を超える文は書き直す**
- 「〜することができます」などの冗長表現を使わない（「〜できます」）
- 常体（だ・である）を混ぜない

### 表記の統一

| 使う | 使わない |
|---|---|
| 出来上がり線 | できあがり線 |
| フタ（縫って作るフタ） | ふた ※「鍋のふた」など実物の蓋はひらがな |
| まち針 | 待ち針 |
| 中表 | なか表 |
| ひも | 紐 ※「抱っこ紐」のような複合語は漢字 |

### 用語

- 実在しない用語を作らない。過去に「引き抜き袖付け」という存在しない言い方を書いていました
  （正しくは「脇を縫う前の平らな状態で袖を付ける」）
- 迷ったら[用語集](../yougoshu.html)に載っている言い方を使う

## 12. 内容の重複を疑う　【手動】

型紙を増やすときに一番やりがちな失敗です。

- 追加しようとしているものが、**すでにある型紙と同じ物ではないか**
  （実例：「ポケットティッシュケース」を作ったが「ティッシュケース」と同一だった）
- 構成の説明が違うだけで、できあがる物が同じなら**それは重複**
- 重複が見つかったら、片方を消して**リダイレクトページを残す**。URLを消さないこと
- 監査の「`<title>` が他ページと重複」はこの兆候です
