## 7. 2026-09-24 に直したこと

`howto-petsnood` の語彙を「犬」に寄せました（PR #121）。

**根拠**：「スヌード」系16クエリ・159表示に対しクリック1件。検索語は全部
「犬 スヌード 作り方」なのに、ページのタイトル・h1 に「犬」が1文字も
入っていませんでした。一方でページの中身は小型犬・中型犬・大型犬のプリセット、
垂れ耳の犬の食事、材料は「中型犬の目安」と、**実体は犬のページ**です。
タイトルが中身を正しく説明していませんでした。

**変更**：タイトル・h1・description・パンくず・構造化データを「犬用スヌード」に。
ツール画面のタブ名（「ペット」→「ペットスヌード」）は実物なので変えていません。
`howto-petscarf` / `howto-petbowtie` は description のみ「犬・猫の〜」に。

### この変更で証明されていないこと

**「本文の『犬』の出現回数を増やせば順位が上がる」は証明されていません。**

`howto-petbandana`（犬20回・8.4位）と `howto-petsnood`（犬8回・10.6位）の比較は
**n=2の相関であって因果ではありません**。順位は被リンク・内部リンク・ページの
情報量・競合の強さなど多数の要因で決まります。

この変更を正当化しているのは順位理論ではなく、**「タイトルがページの中身を
正しく説明していなかった」という単純な事実**です。SEO効果はおまけと考えてください。

### 検証方法

**2026年10月上旬**にSearch Consoleを再取得し、次を見ます。

- 「犬 スヌード 作り方」の掲載順位（現在13.9位）
- `howto-petsnood` の順位（現在10.62位）とクリック（現在9）

2〜4週間で動かなければ、**この仮説は外れです**。変更は5ファイル・46行なので
戻すのは簡単です。戻したうえで、内部リンクや情報量など別の要因を当たります。

## 7-2. 2026-09-24 に直したこと（三角巾）

`howto-bandana` は **タイトルもdescriptionも既に適切**でした。11.09位＝2ページ目に
いるのが問題で、CTRは順位相応です。なので**内容の差分を埋める**改修にしました。

**見つけたギャップ**

- descriptionは「幼児〜大人サイズ」と言っているのに、本文は「小学生サイズの目安」しか
  具体的に書いていなかった
- 「給食当番」が1回出るだけで、家庭科・保育園など実際の利用場面が薄い
- ゴム付き（かぶるだけ）は縫い方の4-3に手順があるだけで、**どちらを選ぶかの説明が無い**
- 関連リンクにエプロンが無い（コツに「エプロンとお揃い」と書いてあるのに）

**直したこと**

- 冒頭に家庭科・幼児〜大人・ゴムを自然に入れた（語の詰め込みはしていません）
- 「サイズの目安」の表を追加。**数値は型紙のプリセットそのもの**です
  （幼児44×24 / 小学生50×28 / 大人56×32cm）。推測値は書いていません
- 「ゴム付きにするか、結ぶタイプにするか」を独立させた
- 材料に、サイズ別の布の大きさの目安を追加
- 関連リンクの「上履き入れ」を「キッズエプロン」に差し替え（給食セットの導線）

**やらなかったこと**：タイトル変更、description変更、キーワードの追加。
現状で十分機能しているものを触る理由がありません。

**見つけた副産物**：`.g-table` は2列目が `nowrap` 指定で、3列の比較表を置くと
320pxで212pxはみ出しました。表を箇条書きに直し、`check-mobile.js` の検査対象に
このページを追加しています（表があるページは他に無く、抽出検査では拾えませんでした）。

**検証**：10月上旬に「三角巾 作り方」（453表示・11.09位）のほか、
「三角巾 型紙」「三角巾 ゴム」「三角巾 給食」のクエリ群がどう動くかを見ます。

   修正対象ではなく教材です。
2. **三角巾を11位から上げる** — 「三角巾 作り方」だけで453表示。最大の伸びしろ。
   給食当番・子供用・大人用といった検索意図に足りているか確認する。
3. **英語トップの正体を確定** — GA4の国別の滞在時間と `open_tool` 発火率。
   ここが通過客なら、英語版への投資判断が変わります。
   **あわせて `open_tool` の `from_kind=howto` と `print_pattern` の実数**も見ます。

   GA4はクラウドから見られないので、手元のPCでの作業になります。
4. **アフィリエイトの現実的な見積り** — 和文howtoが月200クリック前後。
   材料リンクのクリック率を2〜3%とすると月4〜6クリック。
   Amazonアソシエイトの180日・3件ルールに対して余裕はありません。
   日本（`katagami-22`）を軸に考えるのが現実的です。

## 9. 数字の扱いで気をつけること

- **クエリCSVの表示回数（4,626）は全体（10,459）の44%しかありません。**
  残りは匿名化クエリとして除外されています。クエリ側の合計で全体を語らないこと。
- **ページCSV（10,765）と日付・国・デバイス（10,459）も一致しません。** 集計の丸めです。
- **表示が1桁のページで CTR を語らないこと。** 1表示・1クリックはCTR100%です。
- 「0クリックだから改善対象」ではありません。**順位と表示回数を必ず一緒に見ます。**
