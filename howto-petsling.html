ペットスリングの作り方

小型犬や猫を入れて斜めがけで運ぶスリング。動物病院への通院や、歩き疲れたときの抱っこに使えます。両手が空くので階段や電車でも安心です。体重がかかるので、丈夫な生地と2度縫いで作ってください。飛び出し防止のリードは必ず付けます。

1. 材料と道具

材料（小型犬サイズの目安）

  • 表布（帆布8〜11号、デニムなど丈夫な生地）— 約 110cm幅 × 100cm
  • 裏布（メッシュや薄手コットン）— 同量
  • アクリルテープ（ショルダー用、幅広）または共布 — 指定の長さ
  • 移動カン・ナスカン — 各1〜2個
  • 接着芯（厚手）— 本体分

道具

  • ミシン（または針と糸）
  • チャコペン・鉛筆
  • 定規・はさみ
  • アイロン
  • まち針またはクリップ

2. 型紙の作り方（カタガミで自動生成）

カタガミの型紙ツールを使うと、仕上がりサイズを入力するだけで縫い代付きの型紙を自動計算してA4に分割印刷できます。

  1. ツールを開く
    型紙ツールを開き、上部タブの「ペット」→「ペットスリング」を選択します。
  2. サイズを入力する
    「本体の長さ」「袋の深さ」「マチ」「ショルダー長さ」「ショルダー裁ち幅」を入力します。猫・超小型犬／小型犬／中型犬のプリセットがあります。
  3. 縫い代を設定する
    下部スライダーで縫い代幅を選びます（初心者は 1.0〜1.5 cm がおすすめ）。
  4. 印刷する
    「印刷する（A4・実寸）」ボタンを押し、印刷ダイアログで倍率 100%・用紙に合わせるをオフにして印刷します。 1枚目の案内シートにある50mm校正枠を定規で確認してください。

3. 布の裁断

  1. ペットを測る
    丸まったときの体長と、体高を測ります。スリングは中で丸まる姿勢になるので、立ったときの寸法より小さめで足ります。
  2. 型紙を布に写す
    スリング本体（底を「わ」に置く）・ショルダー・飛び出し防止リードの3パーツを写します。
  3. 裁断する
    本体を表布・裏布 各1枚、ショルダーを1本、リードを1本裁ちます。
  4. 接着芯を貼る
    表布の裏面に厚手の接着芯を貼ります。体重を支えるので、ここは省かないでください。

4. 縫い方

4-1. ショルダーとリードを作る

  1. ショルダーを4つ折りにしてアイロンで押さえ、両端をステッチします。幅広に作ると肩が痛くなりません。
  2. 移動カンを通しておきます。ペットを入れた状態で長さを調節できるようにするためです。
  3. リードも同じように4つ折りにして縫い、片端にナスカンを付けます。

4-2. 脇を縫ってマチを作る

  1. 本体（表布）を底で中表に二つ折りにし、両脇を縫います。
  2. この縫い目は必ず2度縫いしてください。体重が直接かかる場所です。1本目の1mm内側にもう1本走らせます。
  3. 底の角を三角につまみ、マチの寸法の位置で縫って余分を1cm残して切り落とします。ここも2度縫いを。
  4. 裏布も同じように縫います（片方の脇に返し口として12cm残す）。

4-3. ショルダーとリードを付ける

  1. 表布を表に返し、裏布は裏のまま。表布を裏布の中に、中表になるように入れます。
  2. 袋口を合わせ、両端にショルダーの端を挟みます。ショルダーがねじれていないか確認してください。
  3. 内側の中央に、リードの端を挟みます。ナスカンが袋の中に来る向きです。
  4. 袋口を1周縫います。ショルダーとリードの位置は返し縫いで3往復して補強してください。

4-4. 表に返して確認する

  1. 裏布の返し口から全体を表に返し、返し口を閉じ、裏布を中に押し込みます。
  2. 袋口から5mm内側をぐるりとステッチします。
  3. 使う前に、ペットの体重と同じくらいのもの（水を入れたペットボトルなど）を入れて、縫い目が持つか必ず確認してください。
  4. リードのナスカンは、必ずハーネスに留めます。首輪に留めると、飛び出したときに首に負担がかかります。

✏️ 脇と底の縫い目は必ず2度縫いしてください。ここに全体重がかかります。1本の縫い目が切れた瞬間に落下事故になるので、手間を惜しまないこと。作ったあとは、実際の体重と同じ重さのものを入れて数分ぶら下げ、縫い目に異常がないか確かめてから使ってください。

5. コツと応用

  • リードは必須：飛び出し防止リードなしで使わないでください。猫も犬も、驚くと想像より速く飛び出します。
  • ハーネスに留める：リードは首輪ではなくハーネスに。首輪だと飛び出したときに首を痛めます。
  • ショルダーは幅広に：体重が肩1点にかかります。10cm以上の幅にすると、長時間でも痛くなりません。
