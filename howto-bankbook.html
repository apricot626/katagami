通帳ケースの作り方

通帳・キャッシュカード・印鑑をまとめて入れる二つ折りケース。引き出しに散らばりがちなものが一か所に収まります。内ポケットを縦に縫い分ければカード入れになり、ゴムバンドで留めれば中身が落ちません。上質なハギレの使いみちとしても最適です。

1. 材料と道具

材料（通帳3冊の目安）

  • 表布（リネン・オックス・帆布など）— 約 50cm × 30cm
  • 裏布（薄手コットン）— 同量
  • 内ポケット用布 — 約 40cm × 15cm
  • 接着芯（しっかりめ）— 表布分
  • 平ゴム（0.6cm幅）— 約 30cm、またはスナップボタン 1組

道具

  • ミシン（または針と糸）
  • チャコペン・鉛筆
  • 定規・はさみ
  • アイロン
  • まち針またはクリップ

2. 型紙の作り方（カタガミで自動生成）

カタガミの型紙ツールを使うと、仕上がりサイズを入力するだけで縫い代付きの型紙を自動計算してA4に分割印刷できます。

  1. ツールを開く
    型紙ツールを開き、上部タブの「小物」→「通帳ケース」を選択します。
  2. サイズを入力する
    「通帳の幅」「高さ」「入れる冊数」「内ポケット高さ」を入力します。通帳1〜2冊・3冊・お薬手帳のプリセットがあります。
  3. 縫い代を設定する
    下部スライダーで縫い代幅を選びます（初心者は 1.0〜1.5 cm がおすすめ）。
  4. 印刷する
    「印刷する（A4・実寸）」ボタンを押し、印刷ダイアログで倍率 100%・用紙に合わせるをオフにして印刷します。 1枚目の案内シートにある50mm校正枠を定規で確認してください。

3. 布の裁断

  1. 入れるものを測る
    通帳の幅・高さを測り、入れたい冊数を数えます。冊数から厚みを自動で見込んだ型紙になります。
  2. 型紙を布に写す
    ケース本体と内ポケットを写します。本体には中央の折り位置の印を入れてください。
  3. 裁断する
    本体を表布・裏布 各1枚、内ポケットを1〜2枚裁ちます。
  4. 接着芯を貼る
    表布の裏面にしっかりめの接着芯を貼ります。通帳の重みで型崩れしないようにするためです。

4. 縫い方

4-1. 内ポケットを作る

  1. 内ポケットの上端を1cm→1cmの三つ折りにして縫います。ここが出し入れ口なので、先に始末しておきます。
  2. 2枚使う場合は、高さを変えて段違いに重ねると中身が見分けやすくなります。

4-2. 内ポケットを裏布に付ける

  1. 裏布の表側に、内ポケットを下端と脇をそろえて重ねます。
  2. カード入れにする場合は、この段階で縦にステッチを入れて区切ります。カード1枚あたり幅6cm程度が目安です。
  3. 縫い始め（ポケットの上端）は必ず返し縫いで補強してください。ここから裂けます。
  4. ポケットの下端と両脇を、縫い代の中に入る位置で仮縫いします。

4-3. 表布と裏布を縫い合わせる

  1. 表布と裏布を中表に重ね、返し口を10cmほど残してぐるりと縫います。
  2. 四隅の縫い代を斜めに切り落とします。
  3. 返し口から表に返し、目打ちで角を出してアイロンで整えます。
  4. 周囲から5mm内側をぐるりとステッチします。返し口もこれで閉じられます。

4-4. 折って留め具を付ける

  1. 中央の折り位置で二つ折りにし、アイロンで折り目を付けます。
  2. 実際に通帳を入れて、閉じたときの重なりを確認します。
  3. ゴムバンドを付ける場合は、背の中央に共布のループを渡し、そこに平ゴムを通して本体に回します。
  4. スナップにする場合は、通帳を入れた状態で位置を決めてから打ってください。

✏️ 「入れる冊数」を正直に入力してください。通帳1冊はおよそ3.5mm。3冊入れれば1cm以上になり、そのぶんの厚みを見込まないと閉じたときに表布が引っぱられて口が開きます。印鑑も入れるなら、さらに1冊分多めに見ておくと安心です。

5. コツと応用

  • お薬手帳ケースにも：プリセットの「お薬手帳」を選べば、そのままお薬手帳＋診察券ケースになります。
  • 印鑑用の小袋を：内側に小さなポケットを1つ足しておくと、印鑑が転がりません。
  • ゴムバンドが便利：スナップより着脱がらくで、厚みが変わっても対応できます。
