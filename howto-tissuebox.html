ボックスティッシュカバーの作り方

箱ティッシュにかぶせるカバー。パッケージの派手な柄が隠れるだけで、部屋の印象がずいぶん落ち着きます。天面に取り出し口を開け、側面4枚を縫い合わせるだけの箱型。裾にゴムを通せば、詰め替えても外れません。

1. 材料と道具

材料（標準サイズの目安）

  • 表布（リネン・コットン・帆布など）— 約 60cm × 50cm
  • バイアステープ（取り出し口用）— 約 50cm
  • 平ゴム（0.8cm幅）— 約 60cm
  • 接着芯（薄手）— 天面分（張りを出す場合）

道具

  • ミシン（または針と糸）
  • チャコペン・鉛筆
  • 定規・はさみ
  • アイロン
  • まち針またはクリップ

2. 型紙の作り方（カタガミで自動生成）

カタガミの型紙ツールを使うと、仕上がりサイズを入力するだけで縫い代付きの型紙を自動計算してA4に分割印刷できます。

  1. ツールを開く
    型紙ツールを開き、上部タブの「ホーム」→「ボックスティッシュカバー」を選択します。
  2. サイズを入力する
    「箱の幅」「奥行」「高さ」「取り出し口の幅」「ゆとり」を入力します。標準・薄型・大きめのプリセットがあります。
  3. 縫い代を設定する
    下部スライダーで縫い代幅を選びます（初心者は 1.0〜1.5 cm がおすすめ）。
  4. 印刷する
    「印刷する（A4・実寸）」ボタンを押し、印刷ダイアログで倍率 100%・用紙に合わせるをオフにして印刷します。 1枚目の案内シートにある50mm校正枠を定規で確認してください。

3. 布の裁断

  1. 箱を測る
    ティッシュ箱の幅・奥行・高さを測ります。メーカーによって高さがかなり違うので、実物を測ってください。
  2. 型紙を布に写す
    天面・側面（前後）・側面（左右）の3種類を写します。すべて長方形です。
  3. 裁断する
    天面1枚、側面（前後）2枚、側面（左右）2枚、合計5枚を裁ちます。
  4. 端の処理
    縫い代の端にジグザグミシンをかけておきます。

4. 縫い方

4-1. 取り出し口を作る

  1. 天面の中央、合印のあいだに取り出し口を描きます。幅は箱の取り出し口と同じくらい、高さは2〜2.5cmが目安です。
  2. 描いた線に沿って切り抜きます。角は丸くしておくと、あとでバイアスを付けやすくなります。
  3. 切り口をバイアステープでくるんで縫います。細幅のバイアスを使うと、小さな穴でも沿います。
  4. 取り出し口は大きくしすぎないでください。中身が乾きます。指2本が入る程度で十分です。

4-2. 側面をつなぐ

  1. 側面4枚を、前 → 右 → 後 → 左 の順に中表で縫い合わせ、輪にします。
  2. 最後の1辺は輪になるので布が回りにくくなります。ミシンの腕に通してゆっくり進めてください。
  3. 縫い代を割ってアイロンで押さえます。

4-3. 天面を付ける

  1. 輪にした側面の上端と、天面を中表に合わせます。
  2. まず四隅を合わせてまち針で留め、そのあいだを細かく留めていきます。側面の縫い目が天面の4つの角に来るようにしてください。
  3. 1周縫います。角では針を刺したまま押さえを上げ、布を90度回してから続けます。
  4. 角の縫い代を斜めに切り落とします。

4-4. 裾にゴムを通す

  1. 裾を1cm→1.5cmの三つ折りにし、ゴム通し口を3cm残して縫います。
  2. 平ゴムを通します。長さは裾まわりの実寸の85%程度。通したら端を重ねて縫い留め、通し口を閉じます。
  3. 表に返して箱にかぶせ、ゴムが箱の底に引っかかるか確認したら完成です。

✏️ 取り出し口を大きくしすぎないでください。箱本体の取り出し口より広く開けると、ティッシュが露出して乾きます。また、大きすぎると天面の布が弱くなり、引っぱるたびに歪みます。箱の取り出し口と同じか、やや小さめが正解です。

5. コツと応用

  • 吊り下げにもできる：天面の代わりに底面に取り出し口を作り、上に吊りひもを付ければ、壁や車の背もたれに掛けられます。
  • 裾のゴムが効く：ゴムがないと、ティッシュを引き抜くたびにカバーが持ち上がります。5分の手間で使い勝手が変わります。
  • ウェットティッシュにも：サイズを変えれば、ウェットティッシュのケースカバーになります。
